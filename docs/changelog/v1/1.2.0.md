# Release v1.2.0

## Features & Improvements

### Search & User Experience
- Clipboard Integration: Added a dedicated paste button next to the primary search input to quickly insert queries or links directly from the clipboard.
- Context-Aware Link Detection: Automatically inspects clipboard content on window focus to adjust the button label dynamically (e.g., displaying "Paste link" when a valid URL is copied).
- Responsive UI Alignment: Adjusted search bar action layouts across desktop and mobile screens for seamless integration alongside search history controls.
