# Release v1.1.0

## Features & Security Improvements

### Configuration & Data Security
- Encryption at Rest: Added Fernet cryptography support to encrypt configuration and sensitive credentials stored on disk.
- API Authentication: Introduced bearer token and API key support (MV_AUTH_TOKEN) for securing server endpoints.
- Credential Masking: Masked sensitive fields (such as Spotify client secrets and ARLs) in server API responses and UI configuration inputs.

### Operational & Container Reliability
- Safe Process Reclamation: Refined start.sh port cleanup to gracefully terminate existing Music Vault processes using SIGTERM, avoiding abrupt process kills and preventing accidental termination of non-Music Vault services.
- Docker Startup Auto-Update: Added a container entrypoint script to refresh yt-dlp on startup, ensuring fallback downloads remain functional against YouTube changes.

### User Interface
- Security Diagnostics: Added status indicators in the system panel reflecting config encryption mode (Encrypted vs Obfuscated) and auth status.
- Search Dropdown Alignment: Refined hero search result dropdown layout, left-alignment, and thumbnail presentation.
